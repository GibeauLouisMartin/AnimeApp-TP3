# Anime App - TP2

## Thème choisi

Application qui liste des animes populaires et permet de suivre combien ont été regardés.

## Fonctionnalités

- Liste de 6 animes avec titre et description

- Cliquer sur un titre pour voir/masquer la description

- Compteur "Nombre d’animes regardés" avec +1/-1

- Switch mode clair / sombre

- Couleurs des Cards et titres adaptées à chaque anime

## Lancer le projet

1. Cloner le dépôt

2. Ouvrir dans Android Studio

3. Run sur un émulateur ou téléphone physique

## Organisation du projet

- `data` → data class Anime

- `ui/screen` → MainScreen

- `ui/theme` → couleurs et thème

- `MainActivity` → point d’entrée

## Notes

- Projet compatible Jetpack Compose

- SDK minimal : 24
